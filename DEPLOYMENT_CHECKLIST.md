## 🚀 Quick Start - Deployment Steps

### 1. Push to GitHub (if not already done)
```bash
cd "c:\Users\poude\Desktop\Guides Nepal"
git init
git add .
git commit -m "Initial commit with deployment config"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/guides-nepal.git
git push -u origin main
```

### 2. Deploy Frontend on Vercel
1. Go to https://vercel.com/dashboard
2. Click "Add New Project"
3. Select your GitHub repo
4. **Root Directory**: `frontend`
5. Add Environment Variables:
   - `VITE_SUPABASE_URL` = `https://YOUR_PROJECT_REF.supabase.co`
   - `VITE_SUPABASE_PUBLISHABLE_KEY` = `<SUPABASE_PUBLISHABLE_KEY>`
   - `VITE_API_URL` = (leave empty - will use default backend once deployed)
6. Click Deploy
7. **Copy the deployed URL** (e.g., `https://guides-nepal-frontend.vercel.app`)

### 3. Deploy Dashboard on Vercel
1. Go to https://vercel.com/dashboard
2. Click "Add New Project" (same repo)
3. **Root Directory**: `dashboard`
4. Add same Environment Variables as frontend
5. Click Deploy
6. **Copy the deployed URL** (e.g., `https://guides-nepal-dashboard.vercel.app`)

### 4. Deploy Backend on Render
1. Go to https://render.com/dashboard
2. Click "New +" → "Blueprint"
3. Connect your GitHub repo
4. Select `render.yaml` blueprint
5. Verify environment variables in `render.yaml`:
   - Update `BACKEND_CORS_ORIGINS` with your Vercel URLs from steps 2-3
6. Click "Create New Blueprint"
7. **Copy the deployed URL** (e.g., `https://guides-nepal-backend.onrender.com`)

### 5. Update Vercel Environment Variables (Final Step)
After backend deployment, go back to each Vercel project and add:
- `VITE_API_URL` = `https://guides-nepal-backend.onrender.com/api/v1`

Then redeploy both frontend and dashboard on Vercel.
